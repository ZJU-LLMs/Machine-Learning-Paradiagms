# 2. 降维

### 背景
在许多现实数据集中，样本由高维特征向量表示，维度可达数百、数千甚至更高。高维数据带来了“维度灾难”：随着维度增加，样本空间呈指数级膨胀，有限数据变得极度稀疏，基于距离或密度的分析方法趋于失效。同时，高维特征中往往存在大量噪声、冗余或高度相关的变量，直接处理不仅计算开销大，还可能影响模型性能与可解释性。

降维的核心目标是将高维数据变换到一个低维空间，同时尽可能保留原始数据的关键结构。这种低维表示通常具有以下益处：(1) 减少存储和计算开销；(2) 抑制噪声，提升下游任务的泛化性能；(3) 使数据得以可视化（如降至 2 或 3 维），便于人类理解与探索；(4) 提取有意义的潜在因子或特征，服务于分类、聚类等后续分析。

降维方法有悠久的发展历史，从经典的线性投影（如主成分分析）到基于流形学习的非线性嵌入（如 Isomap、LLE、t‑SNE），再到利用深度神经网络的自编码器，形成了丰富的技术体系。Fodor (2002) 和 Van Der Maaten 等 (2009) 的综述对该领域进行了系统整理 [1, 2]。

### 问题定义
给定 $N$ 个高维样本组成的矩阵 $\mathbf{X} = [\mathbf{x}_1, \dots, \mathbf{x}_N] \in \mathbb{R}^{D \times N}$，其中 $D$ 为原始维度。降维的目标是寻找一个映射 $f: \mathbb{R}^D \to \mathbb{R}^d$（$d \ll D$），将每个样本 $\mathbf{x}_i$ 变换为低维表示 $\mathbf{y}_i = f(\mathbf{x}_i) \in \mathbb{R}^d$，且使得低维表示尽可能保留原始数据的某种重要结构信息。对于线性降维，映射通常为 $\mathbf{Y} = \mathbf{W}^T \mathbf{X}$，其中 $\mathbf{W} \in \mathbb{R}^{D \times d}$ 为投影矩阵。对于非线性降维，$f$ 可以为非参数隐式映射（如流形学习）或由神经网络参数化（如自编码器）。保留的结构信息通常包括：

+ **方差结构**：使低维数据沿某些方向保持最大的变异性（如 PCA）。
+ **距离结构**：尽可能保持样本间成对距离或相似度（如 MDS、Isomap）。
+ **邻域结构**：使原空间中靠近的点在低维空间中依然靠近（如 LLE、拉普拉斯特征映射、t‑SNE）。

评估降维效果通常依赖间接指标，如下游任务精度，或对于可视化通过视觉判断类别分离程度，也可采用重构误差或保留的方差比例等。

### 经典方法
降维方法大致可分为线性降维、非线性流形学习、以及基于神经网络的深度降维。

#### 1. 线性降维
线性降维通过线性投影将数据映射到低维子空间，计算高效且易于解释。

**（1）主成分分析（PCA）**

PCA 寻找数据方差最大的 $d$ 个正交方向（主成分），将数据投影到这些方向上。具体地，对数据协方差矩阵进行特征值分解或奇异值分解，选取前 $d$ 个最大特征值对应的特征向量构成投影矩阵。该方法由 Pearson (1901) 首次提出几何形式，后由 Hotelling (1933) 系统化为统计方法 [3, 4]。PCA 能保留最大方差，消除线性相关，广泛用于特征提取、数据白化与可视化。

**（2）经典多维缩放（Classical MDS）**

若已知样本间的欧氏距离矩阵，MDS 寻找一个低维欧氏嵌入，使嵌入后的成对距离尽可能接近原始距离。当以欧氏距离为输入时，MDS 等价于 PCA；但 MDS 可接受任意距离度量。Torgerson (1952) 提出了经典 MDS 的推导框架 [5]。

**（3）线性判别分析（LDA）**

LDA 是一种监督线性降维方法。它寻找投影方向，使得投影后不同类别的均值之间尽可能远离，同时各类别内部散度尽可能小。Fisher (1936) 首次提出二分类情况，后被推广至多类 [6]。LDA 在分类前置降维、人脸识别等领域应用广泛。

**（4）独立成分分析（ICA）**

ICA 假设观测信号是若干独立源信号的线性混合，旨在恢复这些独立分量。不同于 PCA 追求方差最大且去相关，ICA 追求分量之间的统计独立。Comon (1994) 对 ICA 进行了系统化阐述，奠定了该方法的理论基础 [7]。ICA 广泛用于盲源分离，如脑电图信号分析。

**（5）非负矩阵分解（NMF）**

NMF 将非负数据矩阵 $\mathbf{X}$ 近似分解为两个非负矩阵 $\mathbf{W}$ 和 $\mathbf{H}$ 的乘积，其中 $\mathbf{H}$ 的列可视为低维表示。由于非负约束，结果具有可加性、部分表达的特性，便于解释。Lee 和 Seung (1999) 在《自然》上发表的论文提出了 NMF 的简单迭代算法，并展示了其在人脸图像局部特征学习上的优势 [8]。

#### 2. 非线性流形学习
当数据分布在高维空间中的非线性低维流形上时，线性方法难以捕获其内在结构。流形学习通过保持局部几何特性来展开这个低维结构。

**（1）Isomap**

Isomap 基于 MDS，但用**测地距离**代替欧氏距离来刻画非线性流形上的真实距离。测地距离由近邻图上的最短路径近似。Tenenbaum, de Silva 和 Langford (2000) 在《科学》上发表了 Isomap，成功恢复了人脸姿态与手写笔迹等内在低维变量 [9]。

**（2）局部线性嵌入（LLE）**

LLE 假设每个样本可被其近邻线性重构，且该重构权重在低维空间中应保持不变。通过求解稀疏特征值问题，得到全局的低维坐标。Roweis 和 Saul (2000) 在《科学》上同时发表了 LLE，展示了在表情、姿态等数据集上的出色展开效果 [10]。

**（3）拉普拉斯特征映射**

拉普拉斯特征映射通过构建样本间的相似图，并求解图拉普拉斯矩阵的广义特征值问题，使原空间中距离近的点在低维空间中映射得近。Belkin 和 Niyogi (2002) 提出了该方法，并建立了其与热核、谱图理论的联系 [11]。

**（4）t‑分布随机邻域嵌入（t‑SNE）**

t‑SNE 是面向可视化的非线性降维方法。它将高维点之间的欧氏距离转换为条件概率（表示近邻相似性），低维空间中使用 t‑分布（重尾分布）定义类似概率，并最小化两个分布间的 KL 散度。van der Maaten 和 Hinton (2008) 提出 t‑SNE，有效缓解了传统 SNE 的拥挤问题，成为单细胞测序、深度学习特征可视化的标准工具 [12]。

**（5）统一流形逼近与投影（UMAP）**

UMAP 基于黎曼几何与拓扑数据假设，构建加权近邻图，并优化低维表示使得模糊拓扑结构与原图尽量一致。McInnes, Healy 和 Melville (2018) 提出了 UMAP，在保留全局结构方面通常优于 t‑SNE，且运行更快，可扩展至大规模数据 [13]。

**（6）扩散映射**

扩散映射通过定义数据上的马尔可夫转移矩阵，模拟随机漫步，其特征函数可提供数据的低维参数化。Coifman 和 Lafon (2006) 提出了扩散映射，它能挖掘多尺度几何结构，对噪声鲁棒 [14]。

#### 3. 深度降维：自编码器
深度神经网络可以通过自编码器架构学习非线性降维映射。自编码器由编码器 $f_{\mathbf{e}}$ 和解码器 $f_{\mathbf{d}}$ 组成，通过最小化重构误差 $|\mathbf{x} - f_{\mathbf{d}}(f_{\mathbf{e}}(\mathbf{x}))|^2$ 来训练，编码器的输出即为降维表示。

**（1）经典自编码器与深度自编码器**

Rumelhart 等 (1986) 在反向传播框架下引入了自编码器作为特征提取器 [15]。Hinton 和 Salakhutdinov (2006) 使用受限玻尔兹曼机逐层预训练，成功训练了深度自编码器，极大推动了深度降维在文档检索、图像压缩等任务上的应用 [16]。

**（2）变分自编码器（VAE）**

VAE 将自编码器纳入概率图模型框架，迫使隐变量服从先验分布（如标准高斯），并最大化证据下界（ELBO）。Kingma 和 Welling (2014) 提出 VAE，其隐变量可视为概率降维表示，既可用于重构，又可生成新样本，在半监督学习和无监督表示学习中影响深远 [17]。

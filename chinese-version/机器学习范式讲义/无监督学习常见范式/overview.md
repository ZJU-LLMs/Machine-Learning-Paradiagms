# 无监督学习常见范式

无监督学习（Unsupervised Learning）不依赖外部标签，直接从数据自身中寻找结构、规律或表征。根据探索目标的不同，它可以分化为聚类、降维、密度估计、关联规则挖掘、异常检测以及图嵌入与社区发现等类型，每一类回应不同的问题，也为后续的监督学习或数据分析任务提供支撑。



聚类（Clustering）将样本划分为若干个簇，目标是让簇内的样本彼此相似、簇间的样本差异尽量大。常见的聚类方法包括 k‑means、层次聚类、DBSCAN 和高斯混合模型，它们各自在簇的形状假设、对噪声的容忍度和可解释性上有所不同。



降维（Dimensionality Reduction）把高维数据映射到低维空间，同时尽可能保留数据中的关键结构。主成分分析（PCA）侧重于保留最大方差方向，t‑SNE 和 UMAP 则更关注局部近邻关系，常用于可视化和特征去噪。



密度估计（Density Estimation）学习数据的概率密度函数，据此可以判断新样本的似然程度，也可以用于生成新样本。传统方法如核密度估计和高斯混合模型，与此互补的是深度生成模型中的归一化流和扩散模型等。



关联规则挖掘（Association Rule Mining）致力于从数据中发现频繁共现的模式或强关联规则，一般通过支持度和置信度等指标进行筛选。典型应用场景是购物篮分析，也可以在推荐系统中帮助发现物品之间的搭配关系。



异常检测（Anomaly Detection）的目标是识别出那些显著偏离大多数数据分布的样本。方法可以基于密度、基于重构误差，也可以将其建模为单类分类问题。这类技术在欺诈检测、工业缺陷识别等场景中有大量实际应用。



这些无监督学习范式并不是完全割裂的，比如密度估计和异常检测常常一起使用，降维也可以看作一种特征学习，能为聚类或关联规则挖掘提供更紧凑的输入。将它们与前述监督学习范式配合使用，往往能构成更完整的机器学习解决方案。

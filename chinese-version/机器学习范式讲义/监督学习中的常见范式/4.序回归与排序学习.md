# 4. 序回归与排序学习

## 序回归与排序学习
### 背景
在标准分类任务中，不同类别被视为地位平等的离散标签，将某一样本错判为相邻类别与错判为遥远类别，损失完全相同。然而大量现实场景中的标签具有内在的顺序结构。例如，电影评分 1–5 星，将 5 星错判为 4 星的代价远低于错判为 1 星；疾病严重程度从“健康”到“轻度”“中度”“重度”存在递进关系；年龄分组、收入水平、教育程度等均是有序类别。此类问题若直接当作标准多分类求解，将丢失类别间的单调顺序信息，也无法体现不同错分距离带来的不同代价。

排序学习则起源于信息检索领域。搜索场景下，目标不是为每个文档独立分类，而是基于其与查询的相关程度，将候选文档按相关性从高到低排序。评价指标（如 NDCG、MAP）关注排序的正确性而非分类准确率。排序学习将这种排序需求形式化为一类机器学习任务，并在推荐系统、问答匹配、计算广告等领域得到广泛运用。

因此，序回归与排序学习的共同动机是：当输出空间具有自然的序关系时，学习算法应当利用序信息来改善预测质量，使模型在序相关的评价指标上取得优良表现。

### 问题定义
**序回归**给定训练集 $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^{N}$，其中 $\mathbf{x}_i \in \mathbb{R}^d$ 为特征向量，标签 $y_i$ 取自具有全序关系的有序类别集合 $\{1, 2, \dots, K\}$，且类别间存在顺序 $1 \prec 2 \prec \dots \prec K$。目标是学习一个映射 $h: \mathbb{R}^d \to \{1, \dots, K\}$，使得期望损失最小。常用损失函数计及预测标签与真实标签之间的绝对距离，如平均绝对误差或二次加权 Kappa 系数。

**排序学习**给定一系列查询 $\{q_i\}_{i=1}^{M}$，每个查询 $q$ 对应一组文档 $\{\mathbf{x}_j^{(q)}\}$ 及其相关性标注 $y_j^{(q)}$（可以是二值、多级有序或实数）。目标是为各查询学习一个排序函数 $f$，对文档进行打分并按分数降序排列，使得整体排序质量在 NDCG、MAP 等序相关指标上最优。

### 经典方法
#### 1. 序回归方法
序回归方法主要分为数据层面、阈值模型、损失函数修正、基于二分类的分解以及深度学习方法。

**（1）数据层面与朴素方法**

一种朴素方法是直接将其作为标准多分类或回归问题求解，忽略或部分利用序信息。稍微精细的做法是对有序标签进行编码，如用累积概率将序回归转化为多个叠加的二分类问题。Frank 和 Hall (2001) 最早系统性地提出将序回归分解为多个二分类子问题的框架 [1]。

**（2）阈值模型**

这是最经典的一类方法。假设存在一个潜在连续评分函数 $f(\mathbf{x})$ 和一组递增的阈值 $\theta_1 \leq \theta_2 \leq \dots \leq \theta_{K-1}$，预测规则为 $h(\mathbf{x}) = k$ 当且仅当 $\theta_{k-1} < f(\mathbf{x}) \leq \theta_k$（其中 $\theta_0 = -\infty$，$\theta_K = +\infty$）。目标是从数据中同时学习 $f$ 和 $\theta$。

+ **支持向量序回归（SVOR）**：Chu 和 Keerthi (2007) 将支持向量机扩展到序回归，提出 SVORIM（隐式约束）和 SVOREX（显式约束）两种形式，对违反顺序间隔的样本施加惩罚 [2]。
+ **比例几率模型（Proportional Odds Model）**：McCullagh (1980) 提出经典统计方法，利用累积概率建模 $P(y \leq k | \mathbf{x}) = \sigma(\theta_k - f(\mathbf{x}))$，其中 $\sigma$ 为逻辑函数，通过最大似然估计拟合 [3]。该模型假设协变量对累积几率的影响成比例。
+ **神经网络阈值模型**：Cheng 等 (2008) 将阈值模型思想融入神经网络，共享隐藏层并在输出层引入有序阈值约束，使用反向传播联合优化 [4]。

**（3）损失函数修正**

直接修改分类损失的权重，使远离真实标签的错误受到更大惩罚。

+ **二次加权 Kappa 损失**：Cohen (1968) 提出二次加权 Kappa 系数作为有序类别一致性的评价指标 [5]，后续被用作序回归的优化目标，权重与类别间距离的平方成正比。
+ **绝对误差与 Earth Mover's Distance**：Hou 等 (2016) 提出基于 Earth Mover's Distance 的有序熵损失，直接最小化真实类别与预测分布间的有序 Earth Mover's Distance，在面部年龄估计等任务中显著提升了有序预测精度 [6]。

**（4）基于二分类的分解**

将 $K$ 类序回归转化为 (K-1) 个二分类问题。

+ **Frank-Hall 分解**：Frank 和 Hall (2001) 提出第 $j$ 个分类器判断 $y > j$ 是否成立，预测时整合各基分类器输出可得到完整后验概率分布。此法实现简单，可直接套用成熟的二分类模型 [1]。
+ **增强二分类分解**：Li 和 Lin (2007) 提出在二分类分解框架下引入单调性约束，确保各类别概率的一致性 [7]。

**（5）深度学习方法**

+ **CORN（Conditional Ordinal Regression Network）**：Zhao 等 (2020) 提出为每个类别输出条件概率 $P(y > k | \mathbf{x})$，再转换为序类别概率，使用负对数似然训练，在多个序回归基准上取得优异效果 [8]。
+ **Ordinal Entropy**：Hou 等 (2016) 设计专门的有序熵损失，用 Earth Mover's Distance 度量预测分布与真实分布之间的距离 [6]。
+ **POE（Probabilistic Ordinal Embeddings）**：Li 等 (2021) 提出在嵌入空间中同时学习样本的有序表示与类别阈值，适用于大规模序回归 [9]。

#### 2. 排序学习方法
排序学习方法通常分为三种范式：点方式（Pointwise）、对方式（Pairwise）和列表方式（Listwise）。刘铁岩 (2009) 在其综述专著中对这三种方法进行了系统总结 [10]。

**（1）点方式（Pointwise）**

将排序简化为对每个文档独立打分，预测其绝对相关性分值，本质上退化为一个序回归或回归问题。

+ **回归排序**：Cossock 和 Zhang (2006) 使用均方误差回归拟合相关性等级，理论分析证明了在一定条件下回归模型可产生一致的排序结果 [11]。
+ **McRank**：Li 等 (2008) 将多分类用于多级有序标签排序，用期望相关性作为排序分数 [12]。

**（2）对方式（Pairwise）**

聚焦于文档的相对顺序，将排序问题转化为对文档对的偏好比较。

+ **Ranking SVM**：Herbrich 等 (2000) 将文档对的相对顺序视作分类间隔，用 SVM 最小化排序损失 [13]。Joachims (2002) 将其系统化并应用于搜索引擎的点击数据 [14]。
+ **RankNet**：Burges 等 (2005) 使用神经网络对文档对打分，基于交叉熵损失衡量两者分数的差异与实际偏好的匹配程度 [15]。
+ **LambdaRank**：Burges 等 (2006) 在 RankNet 的基础上进一步将梯度直接用排序指标（如 NDCG）的增量加权，使得梯度不仅反映偏好匹配，还体现排序结果的指标变化 [16]。
+ **Frank-Wolfe 排序**：Usunier 等 (2009) 提出结构 SVM 排序方法，直接在结构化输出空间上优化排序损失上界 [17]。

**（3）列表方式（Listwise）**

直接优化整个文档列表的排序指标。

+ **ListNet**：Cao 等 (2007) 将排序视为对列表概率分布的拟合问题，用交叉熵度量预测排序与真实排序之间的差距，首次系统提出了列表级损失 [18]。
+ **ListMLE**：Xia 等 (2008) 以最大化真实排序顺序的似然为目标，提出基于最大似然估计的列表式方法 [19]。
+ **LambdaMART**：Burges (2010) 将对方式中的 LambdaRank 梯度与梯度提升决策树（MART）结合，成为工业界常用的排序学习基线 [20]。
+ **近似 NDCG 损失**：Qin 等 (2010) 通过光滑逼近直接优化 NDCG [21]。后续工作如 Taylor 等 (2008) 也探讨了直接优化信息检索指标的可微松弛 [22]。
+ **SoftRank**：Taylor 等 (2008) 引入随机扰动将排序指标的离散阶梯函数平滑化，利用梯度下降直接优化 [22]。

**（4）深度语义匹配与预训练适配**

搜索和推荐领域的深度排序模型通常采用双塔架构或预训练语言模型进行语义匹配。

+ **双塔模型（Two-Tower）**：Huang 等 (2013) 提出 DSSM，分别对查询和文档编码为固定维向量，再通过余弦相似度计算匹配度，是双塔架构的奠基性工作 [23]。
+ **预训练交叉编码器**：Nogueira 和 Cho (2019) 使用 BERT 的交叉编码器架构直接将查询-文档对输入预训练模型进行重排序，效果优异但计算代价高，通常用于重排序阶段 [24]。
+ **ColBERT**：Khattab 和 Zaharia (2020) 提出延迟交互机制，分别编码查询和文档后，在词粒度上计算相似度，在效率与效果间取得平衡 [25]。
